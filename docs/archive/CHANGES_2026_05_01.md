# System Changes - 2026-05-01
## Cohort Filter Over-Filtering Resolution

---

## Problem Statement

**Symptom:** Evaluation accuracy dropped from 60% to 20% after Qdrant metadata sync.

**Root Cause:** INNER JOIN in temporal metadata enrichment dropped 378/509 documents (74%) with empty `cohort_years`.

**Impact:** System over-filtered documents, returning insufficient results for queries.

---

## Changes Applied

### 1. Database Query Fix - LEFT JOIN Implementation

**File:** `LangGraph/src/agent/clients/lightrag_client.py:1192`

**Before:**
```sql
INNER JOIN temporal_metadata tm ON tm.doc_id = lds.id
```

**After:**
```sql
LEFT JOIN temporal_metadata tm ON tm.doc_id = lds.id
```

**Rationale:**
- INNER JOIN dropped all documents without temporal_metadata rows
- LEFT JOIN preserves all documents, treats empty `cohort_years` as universal
- Documents without metadata now pass through filter instead of being excluded

**Impact:**
- Document coverage: 131/509 (26%) → 331/509 (65%)
- Accuracy: 20% → 60% (baseline restored)
- Enrichment: 0% → 60% (51-78 items/query)

### 2. Filter Logic Validation

**File:** `LangGraph/src/agent/graphs/query_graph.py:245-266`

**Verified Behavior:**
- Filter only drops explicit cohort mismatches
- Empty `cohort_years` treated as universal (matches all cohorts)
- NULL values from LEFT JOIN handled correctly

**No changes needed** - logic was correct, INNER JOIN was the blocker.

### 3. Cohort Metadata Distribution Analysis

**Query executed:**
```sql
SELECT
    COUNT(*) as total,
    COUNT(CASE WHEN tm.cohort_years IS NOT NULL AND tm.cohort_years != '[]' THEN 1 END) as with_cohort
FROM lightrag_doc_status lds
LEFT JOIN temporal_metadata tm ON tm.doc_id = lds.id
WHERE lds.workspace = 'default';
```

**Results:**
- Total docs: 509
- Docs with cohort metadata: 131 (26%)
