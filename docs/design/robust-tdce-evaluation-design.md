## Problem Statement
Standard RAG ablation studies (HitRate/MRR) measure semantic relevance but fail to capture **temporal correctness**. In the Vietnamese higher education domain, an answer from an expired regulation (e.g. 2018 regime for a 2022 cohort) is "relevant" but **factually incorrect**. The system needs an evaluation framework that explicitly rewards following amendment chains and cohort boundaries.

## What Makes This Cool
It moves beyond "Search" evaluation into "Policy" evaluation. By using **Temporal Document Chain Evaluation (TDCE)**, the thesis can prove that the system understands the **law's evolution**, not just keywords. The "Contrastive Pairs" add a "causal" proof: "The system performs a **Temporal Response Pivot**, returning Doc A for K2015 and Doc B for K2022, even though the text is 90% identical."

## Constraints
- Must be theoretically sound for a Master's Thesis defense.
- Must handle Vietnamese administrative document numbering (e.g. 141/QD-DHCNTT).
- Must run locally with available LLM resources (handling timeouts/failures).

## Metrics Definition (TDCE Framework)
1. **Amendment Precision@k (AP@k)**: Scores correct identification of the *latest* revision in an amendment chain, penalizing superseded versions.
2. **Temporal Cascade Hit Rate**: Success in traversing chains correctly, especially when the query anchors to a non-latest but valid historical version.
3. **Authority Resolution Score**: Accuracy in selecting the correct authority level (e.g., UIT-local vs. National MOET) among colliding policies.
4. **Cohort Coverage Rate**: Accuracy in targeting specific student enrollment years vs. universal rules.
5. **Amendment Recall@k**: Capturing all relevant related amendments beyond the primary document number.
6. **Temporal Displacement Rate**: Measures the percentage of results incorrectly selected from an inactive temporal context. This includes both version errors within the same chain (supersession) and general noise from unrelated but expired documents.
7. **Response Pivot Accuracy**: Calculated by linking contrastive pairs (e.g., ID 100a and 100b). A "Pivot" is successful if the system returns the correct document for both queries, proving it is sensitive to the cohort/date variable rather than just keyword overlap.

## Premises
1. Standard HitRate/MRR are insufficient for temporal RAG because they don't penalize 'temporally displaced' answers.
2. A 'theoretically sound' evaluation must explicitly measure the system's ability to traverse the amendment chain (Supersession accuracy).
3. Counterfactual testing (same question, different cohort/date) is the strongest way to prove 'Temporal Intelligence'.

## Approaches Considered
### Approach A: Robust TDCE + Contrastive Eval (RECOMMENDED)
Summary: Fix the TDCE framework, add counterfactual pairs, and perform qualitative failure analysis.
Effort: M
Risk: Low
Pros:
- Most academic rigor.
- Provides 6 distinct "Temporal Metrics" (see definitions above).
- Directly proves the system's novelty.
Cons:
- Requires manual creation of contrastive pairs.
- Needs reliable LLM access.

### Approach B: Adversarial LLM Judge
Summary: Use Gemini 1.5 Pro to judge the "Temporal Freshness" of responses.
Effort: S
Risk: Med
Pros:
- Faster to implement.
- No manual metric calculation.
Cons:
- Less "first principles" than TDCE.
- Committee might question the "Judge's" accuracy.

## Recommended Approach
**Approach A: Robust TDCE + Contrastive Eval**
This approach provides the most robust evidence for a thesis. It doesn't just say "the LLM says it's good"; it provides hard metrics on **Amendment Precision** and **Displacement Rate**.
