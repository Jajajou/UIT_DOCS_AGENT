temporal_metadata table schema (relevant columns):

Amendment chain semantics:
- amends_documents: "I replace/modify THIS document" (forward pointer)
- amended_by / amended_by_documents: "I was replaced by THIS document" (reverse pointer)
- Reranker uses amended_by to deprioritize: if doc X has amended_by=[Y], X gets temporal_score=0.3
