<objective>
Fix Bug A3: Add education_system field to distinguish chinh_quy / tu_xa / tien_tien / song_nganh documents.

Purpose: Without this field, 507/QD-DHCNTT (tu xa) is confused with chinh quy Quy che dao tao docs. Students asking about chinh quy get tu xa results mixed in. This field enables correct routing and prevents cross-contamination.

Output: DB schema change + classification backfill + Qdrant payload update + Agent 1 detection + retrieval filter.
</objective>

Create `LangGraph/scripts/backfill_education_system.py` that:

1. Runs ALTER TABLE:
```sql
ALTER TABLE temporal_metadata ADD COLUMN IF NOT EXISTS education_system TEXT DEFAULT 'universal';
```

2. Queries all docs with file_path from lightrag_doc_status JOIN temporal_metadata:
```sql
SELECT tm.doc_id, tm.document_number, lds.file_path
FROM temporal_metadata tm
JOIN lightrag_doc_status lds ON tm.doc_id = lds.id
WHERE tm.workspace = 'uit_docs_agent';
```

3. Classifies each doc using these rules (applied in ORDER -- first match wins):
   - file_path contains 'tu_xa' (case-insensitive) -> 'tu_xa'
   - file_path contains 'tien_tien' (case-insensitive) -> 'tien_tien'
   - file_path contains 'song_nganh' (case-insensitive) -> 'song_nganh'
   - document_number matches pattern for ministry docs: starts with digits + / + (ND-CP|TT-BGD|TT-BGDDT|QD-BGDDT|QD-TTg) -> 'universal'
   - document_number matches DHQG pattern: /QD-DHQG -> 'universal'
   - Everything else from DHCNTT -> 'chinh_quy'

4. Updates temporal_metadata:
```sql
UPDATE temporal_metadata SET education_system = %s WHERE doc_id = %s;
```

5. After all DB updates, scrolls Qdrant collection `lightrag_vdb_chunks` and updates payload `education_system` for each doc using filter-based set_payload (same pattern as `update_qdrant_payloads_for_doc` in lightrag_client.py):
```python
url = f"{QDRANT_BASE_URL}/collections/lightrag_vdb_chunks/points/payload"

    "filter": {"must": [{"key": "full_doc_id", "match": {"value": doc_id}}]}
}
requests.put(url, json=body, timeout=30)
```

6. Prints summary: total docs, per-category counts, Qdrant update count.

Script must use `psycopg2` for direct DB access (same pattern as lightrag_client.py `_get_pg_connection`). Connection: host=localhost, port=5433, user=uitrag (from env or hardcoded fallback), database=lightrag.
