<objective>
Fix Bug A3: Add education_system field to distinguish chinh_quy / tu_xa / tien_tien / song_nganh documents.

Purpose: Without this field, 507/QD-DHCNTT (tu xa) is confused with chinh quy Quy che dao tao docs. Students asking about chinh quy get tu xa results mixed in. This field enables correct routing and prevents cross-contamination.

Output: DB schema change + classification backfill + Qdrant payload update + Agent 1 detection + retrieval filter.
</objective>

**Step 3 -- Classify each doc using these rules (applied in ORDER -- first match wins):**
- file_path contains 'tu_xa' (case-insensitive) -> 'tu_xa'
- file_path contains 'tien_tien' (case-insensitive) -> 'tien_tien'
- file_path contains 'song_nganh' (case-insensitive) -> 'song_nganh'
- document_number matches ministry pattern: starts with digits + / + (ND-CP|TT-BGD|TT-BGDDT|QD-BGDDT|QD-TTg) -> 'universal'
- document_number matches /QD-DHQG -> 'universal'

```python
import requests, json, os

QDRANT_BASE_URL = os.environ.get("QDRANT_BASE_URL", "http://localhost:6333")
KNOWN_OVERRIDES = {"507/QD-DHCNTT": "tu_xa"}

def update_qdrant_for_doc(doc_id: str, education_system: str) -> bool:
    url = f"{QDRANT_BASE_URL}/collections/lightrag_vdb_chunks/points/payload"
    body = {
        "payload": {"education_system": education_system},
        "filter": {"must": [{"key": "full_doc_id", "match": {"value": doc_id}}]}
    }
    r = requests.put(url, json=body, timeout=30)
    return r.status_code == 200

# Load classifications from JSON file (generated by executor from DB query results)
# Usage: python backfill_education_system.py classifications.json [--dry-run]
```
